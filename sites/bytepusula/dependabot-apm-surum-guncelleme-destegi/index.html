Dependabot, ajan paketleri için sürüm güncelleme isteği açabiliyor

GitHub’un APM desteği, yapılandırmadaki Git bağımlılıklarının sürüm takibine odaklanıyor.

BytePusula · 04.11.2026 · 2 dk okuma

Ajan yapılandırmaları da bağımlılık taşıyor

Agent Package Manager, bir projenin beceri ve talimat paketlerine ilişkin bağımlılıklarını dosyada tanımlamasını sağlıyor. GitHub’un 3 Kasım duyurusuna göre Dependabot, apm.yml içindeki desteklenen Git bağımlılıkları için sürüm değişikliği öneren pull request açabiliyor. Depoda apm.lock.yaml bulunuyorsa bu dosya da önerilen değişikliğe göre yeniden üretiliyor. Böylece bir ekip, araç paketindeki değişikliği kod incelemesinde görebiliyor.

Öneriyi birleştirmeden önce içeriğini okuyun

Paket güncellemesi, ajanın izleyeceği talimatların değişmesi anlamına gelebilir. Bu nedenle incelemede yalnız sürüm numarasına bakmak yerine paketin ne eklediğini ve kilit dosyasının nasıl değiştiğini görmek yararlı. Açıklamaya göre otomasyon sürüm güncellemelerini kapsıyor. Güvenlik açığı tespit edildiğinde ayrı bir güvenlik güncellemesi üreteceği taahhüt edilmiyor. Yapılandırma, apm ekosistemi ile dosyanın dizinini ve güncelleme aralığını belirtiyor. Destek GitHub.com planlarında genel kullanıma açık, GitHub Enterprise Server için belirtilen sürüm ise 3.24. Depoda APM yapılandırması yoksa bu duyurunun konusu olan bağımlılık listesi de oluşmuş sayılmaz. Başlangıç noktası proje dosyası.
