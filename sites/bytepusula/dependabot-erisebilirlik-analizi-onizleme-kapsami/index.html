Dependabot, açığı kodunuzun gerçekten çağırıp çağırmadığına bakmayı deniyor

JavaScript ve TypeScript önizlemesi önceliklendirme sağlıyor; ulaşılmaz sonucu güvenlik garantisi veya otomatik kapatma değil.

BytePusula · 01.11.2026 · 2 dk okuma

Sürüm uyarısına çağrı yolu ekleniyor

Dependabot'un yeni erişilebilirlik analizi, savunmasız bir bağımlılığın projede bulunmasının ötesine bakıyor. Amaç, uygulamanın ilgili kod yoluna ulaşıp ulaşmadığını göstererek düzeltme sırasını belirlemeye yardımcı olmak. 28 Ekim duyurusundaki açık önizleme JavaScript ve TypeScript projeleriyle sınırlı; npm, yarn ve pnpm kilit dosyaları destekleniyor. Diğer dillerin aynı kapsamda olduğu belirtilmiyor.

Düşük öncelik, riskin yokluğu değil

Sonuçlar erişilebilir, potansiyel olarak erişilebilir, erişilemez veya analiz edilemedi biçiminde ayrılabiliyor. Potansiyel erişilebilirlik güvenli kabul edilmiyor. Erişilemez sonucu da bağımlılığı güncelleme gereğini kesin olarak ortadan kaldırmıyor; yalnız mevcut analizde bir yol bulunamadığını anlatıyor. GitHub, bu sonuçla uyarıları otomatik kapatmıyor. Eksik analizle gerçekten temiz bir kod tabanını birbirine karıştırmamak gerekiyor.

Ücretsiz önizlemenin hesap sınırı var

Önizleme GitHub Enterprise Cloud kuruluşlarına yönelik; veri yerleşimi kapsamındaki hesaplar da belirtiliyor. Bu dönemde ek Advanced Security lisansı veya analiz için model dakika ücreti istenmediği açıklanıyor. Buna rağmen özellik bütün ücretsiz depolara açılmış değil. GitHub tarafından barındırılan çalıştırıcılar ve ilgili analiz kurulumu gerekiyor. Kendi depolarımızda etkinleştirme veya ücretli plan değişikliği yapılmadı.
