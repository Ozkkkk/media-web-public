Güvenlik

GitHub'ın AI kod taraması, modele giden güvensiz girdiyi izliyor

Açık önizleme, araç kullanan AI uygulamalarındaki saldırı yollarını arıyor; Advanced Security lisansı gerekiyor.

BytePusula · 01.11.2026 · 2 dk okuma

Sorun yalnız üretilen kod değil

GitHub'ın 28 Ekim'de açıkladığı tarama, yapay zekâ uygulamasının çalışma sırasında aldığı girdilere odaklanıyor. Güvenilmeyen bir metnin modele, oradan veri veya araç erişimine uzanan yolu incelemeye çalışıyor. Dolaylı komut enjeksiyonu, hassas bilginin açığa çıkması ve modele gereğinden geniş işlem yetkisi verilmesi, duyuruda belirtilen riskler arasında. Bu kapsam, yalnız sözdizimi hatası aramaktan farklı.

İş akışına ek bir inceleme

Önizleme, pull request süreçlerinde CodeQL yanında çalışacak şekilde anlatılıyor. Amaç geliştiricinin tehlikeli veri akışını daha erken görmesi; bütün saldırıların otomatik engellendiği veya bildirilen sorunun kendiliğinden düzeltildiği söylenmiyor. Model girdisini başka biçimde kodlamak da tek başına kapsamlı savunma kabul edilmemeli. Yetki sınırları ve güvenilmeyen içeriğin nasıl işlendiği uygulama tasarımında ayrıca değerlendirilmek zorunda.

Herkesin hesabına ücretsiz gelmiyor

GitHub.com üzerindeki açık önizleme için GitHub Advanced Security lisansı gerekiyor. GitHub Enterprise Server desteği bu duyurunun kapsamında değil. Dolayısıyla yakın tarihteki başka güvenlik önizlemelerinin ücretsiz koşulları bu ürüne taşınamaz. Haber resmî ürün açıklamasına dayanıyor; bağımsız saldırı testi veya sertifikasyon sunmuyor. Sitemizin deposunda lisans satın alma, özellik açma ya da ayar değişikliği yapılmadı.
